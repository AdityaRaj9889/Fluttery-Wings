# Fluttery-Wings
Fluttery Wings – AAA Tap to Fly game with Flutter 3.24 + Flame 1.22 + GetX. 60fps physics, random pipes, 8 characters, 6 themes, daily rewards, achievements, coins, leaderboard. Glassmorphism UI, real-time shop sync, Die/Watch Ad/Pause → TAP TO FLAP → resume at score 3. Clean SOLID, AdMob ready, Play Store quality | Full template
